## Status vocabulary

- `shipped-local`: implemented and locally runnable.
- `stub-tested`: covered by local unit tests or simulated tools, but not exercised against the live external service.
- `authored-ci-smoke`: CI YAML exists and should run remotely, but this snapshot has not attached a remote run artifact.
- `ci-pending`: requires GitHub Actions remote execution or OIDC.
- `blocked`: a real prerequisite was unavailable during execution.
- `planned`: design exists but no implementation claim is made.
